# Isabelle Victoria

Site oficial da cantora Isabelle Victoria: louvor, moda e propósito.

Página única em `index.html`, com fotos, estilos e scripts embutidos. Basta publicar a pasta em qualquer hospedagem estática (Netlify, GitHub Pages, Vercel).

O vídeo do YouTube na abertura, a música do Spotify e os players externos só funcionam com o site hospedado; aberto direto do computador, a página usa a foto em camadas.

Site e marca desenvolvidos por Moises Silva · [@moisesbsilvaa](https://instagram.com/moisesbsilvaa)
